# DB Visualizer for VS Code

Visualize SQL databases, schemas, relationships, and stored procedures directly within VS Code.

## Features

- **Full Canvas ER Diagram**: Explore database tables and relationships in an interactive editor canvas.
- **Stored Procedures Visualizer**: Inspect SP definitions, input/output parameters, and dependency graphs.
- **Fast Search & Command Palette**: Press `Ctrl+K` to search tables and columns.
- **Pre-configured Production Server**: Connects automatically to `https://dbvisual.fabai.cloud`.

## Usage

1. Click the **$(database) DB Visualizer** item in the bottom status bar or on the activity bar.
2. Sign in with your assigned ID and password.
